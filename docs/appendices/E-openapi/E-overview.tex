La \acs{api} \acs{rest} del SCDEE se documenta mediante un esquema
OpenAPI 3.0 generado automáticamente desde el código fuente con
drf-spectacular (\cref{SEC:DES-API}). El esquema completo expone 72
\textit{endpoints} agrupados en 25 colecciones de recursos. Este anexo
resume el catálogo (\cref{SEC:OPENAPI-CATALOG}) y describe los medios
disponibles para acceder a la especificación detallada
(\cref{SEC:OPENAPI-ACCESS}).
