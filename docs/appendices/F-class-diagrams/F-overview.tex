Este anexo recoge los diagramas de clase del modelo de datos del SCDEE,
generados automáticamente a partir del código mediante el comando
\texttt{graph\_models} de django-extensions. Los diagramas se presentan
a continuación, agrupados en dos bloques: los diagramas por subdominio
(\cref{SEC:CLASS-BY-DOMAIN}) y la vista global del sistema
(\cref{SEC:CLASS-GLOBAL}).
