Con el fichero \texttt{.env} configurado, la primera ejecución completa
se invoca con:

\begin{verbatim}
make setup
\end{verbatim}

Este comando ejecuta secuencialmente \texttt{make keygen},
\texttt{make build}, \texttt{make up}, \texttt{make makemigrations},
\texttt{make migrate}, \texttt{make setup-finish},
\texttt{make createsuperuser} y \texttt{make sftp-watcher}. Al
finalizar, el sistema está completamente operativo con un superusuario
creado y el \textit{watcher} de ingesta \acs{sftp} en ejecución.

Si solo se desea reconstruir las imágenes y arrancar, puede ejecutarse:

\begin{verbatim}
make build
make up
\end{verbatim}
