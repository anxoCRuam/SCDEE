Con el fichero \texttt{.env} configurado, la primera ejecución completa
se invoca con:

\begin{verbatim}
make setup
\end{verbatim}

Este comando ejecuta secuencialmente la construcción de las imágenes
(\texttt{make build}), el arranque de los servicios (\texttt{make up})
y la creación del \textit{bucket} por defecto de MinIO
(\texttt{make setup-finish}). Tras el primer arranque deben aplicarse
las migraciones y crearse el superusuario:

\begin{verbatim}
make migrate
make createsuperuser
\end{verbatim}
