El despliegue requiere las siguientes herramientas instaladas en el
sistema anfitrión: Docker 24.0 o superior con el \dfn{plugin}
\texttt{docker compose} v2, GNU Make 4.0 o superior, y Git para clonar
el repositorio. No se requiere Python, PostgreSQL, Redis ni MinIO en el
anfitrión: todo se ejecuta dentro de contenedores.
