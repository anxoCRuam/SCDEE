El entorno de despliegue requiere las siguientes herramientas instaladas
en el sistema anfitrión:

\begin{itemize}
  \item Docker 24.0 o superior con el complemento \texttt{docker compose}
        v2.
  \item GNU Make 4.0 o superior.
  \item Git, para clonar el repositorio.
\end{itemize}

No es necesario instalar Python, PostgreSQL, Redis ni MinIO en el
anfitrión, ya que todos los componentes se ejecutan dentro de
contenedores Docker.
