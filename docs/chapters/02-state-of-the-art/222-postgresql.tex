PostgreSQL es la base de datos relacional por defecto en proyectos Django
y la elección estándar en la mayoría de despliegues de producción del
marco \cite{postgresql}. Soporta SQL estándar, transacciones \acs{acid},
tipos avanzados como JSONB, índices funcionales y un sistema de
extensiones, todo bajo una licencia permisiva tipo BSD. Para los
requisitos del SCDEE (integridad referencial estricta, transacciones
largas durante la ingesta, consultas complejas para los listados con
filtros y agregaciones para los informes de calificación), PostgreSQL
cubre con holgura todas las necesidades del proyecto sin requerir mayor
justificación.
