El \dfn{backend} implementa medidas de seguridad en tres niveles:

\begin{description}
  \item[Protección de datos en reposo] El \acs{dni} se cifra con
  \acs{aes}-256-\acs{gcm} con \textit{nonce} único por registro y clave
  maestra externa. Las contraseñas se almacenan como \textit{hash} Argon2
  con sal, descartando el texto plano inmediatamente.

  \item[Protección de datos en tránsito] Las páginas servidas a alumnos
  llevan una marca de agua dinámica con nombre, \acs{nia} y fecha. Si la
  descarga no está permitida, el \acs{pdf} se cifra con una clave
  derivada de la sesión del usuario y se sirve con cabeceras
  \acs{http} anti-caché y \acs{url} temporales de corta expiración.

  \item[Auditoría inmutable] Cada operación de negocio con impacto en
  datos genera un registro en una tabla \textit{append-only} de
  PostgreSQL, protegida contra modificaciones mediante un disparador SQL.
  El registro incluye actor, organización, dirección \acs{ip}, tipo de
  evento y datos relevantes.
\end{description}

El cumplimiento del \acs{rgpd} se aborda mediante la combinación de
cifrado en reposo, \textit{soft-delete} de usuarios, auditoría de accesos
y almacenamiento seguro de credenciales.
