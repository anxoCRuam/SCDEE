El backend del SCDEE persiste su modelo de dominio en PostgreSQL siguiendo
el patrón fila compartida con discriminador (\texttt{organization\_id})
introducido en \cref{SS:SOTA-MULTITENANT}. Esta sección describe la
estructura común que comparten todos los modelos
(\cref{SS:DES-MODEL-STRUCTURE}), enumera y agrupa las entidades del dominio
(\cref{SS:DES-MODEL-OVERVIEW}) y desarrolla el mecanismo que garantiza el
aislamiento entre organizaciones inquilinas
(\cref{SS:DES-MODEL-ISOLATION}).
