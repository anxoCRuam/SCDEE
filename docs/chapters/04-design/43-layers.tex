Esta sección desarrolla la organización interna del código del backend,
complementaria al diseño de datos del bloque anterior. Se cubren tres
aspectos: la arquitectura por capas que ordena las responsabilidades
dentro de cada aplicación (\cref{SS:DES-SERVICE-LAYER}), la división del
backend en aplicaciones Django con un dominio funcional propio
(\cref{SS:DES-APPS}) y los puntos donde el sistema admite componentes
intercambiables mediante el patrón \textit{Strategy} (\cref{SS:DES-PLUGINS}).
