La medición de cobertura sobre el conjunto de pruebas unitarias y de
integración alcanza un 88\,\%, con desglose por aplicación y por capa
disponible en \cref{AP:TEST-RESULTS}. La interpretación del valor
requiere matizarla: el sistema mantiene deliberadamente algunas
funciones de soporte que no se invocan en los flujos actuales pero que
se conservan como infraestructura para extensiones previstas, lo que
reduce ligeramente la cobertura medida frente a la cobertura efectiva
sobre el código activo.
